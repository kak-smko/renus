# Project scaffolding

Use `renus create` to generate a project in a new directory. The command accepts a project name, one of three templates, and a database choice:

```bash
renus create <name> [api|mvp|extension] [mongodb|mysql|sqlite|none]
```

For example, create an API project with SQLite:

```bash
renus create inventory api sqlite
cd inventory
renus run dev
```

The `api` template is generated by Renus and includes a `main.py` application. Its database choice selects a MongoDB, MySQL, SQLite, or database-free starter. The `mvp` template fetches the Codenus project; `extension` fetches that project and adds a project-local `renus local` command for managing local extensions. These two templates require network access; the generator attempts to use Git when available and otherwise fetches a GitHub archive.

If the name, template, or database is omitted, the command prompts when running interactively. Defaults for non-interactive selection are `api` and `sqlite`. Names are normalized for use as a directory and Python package name. A non-empty existing directory cannot be used as the destination.

The `mvp` and `extension` templates may additionally offer to install ESLint for their frontends when run interactively.
